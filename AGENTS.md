# Dev Workbench

Support Vietnamese (`vi`) and English (`en`) for every new feature. Localize all user-facing text, including accessibility labels and messages for loading, empty, success, and error states where applicable. Use the existing language selector and preserve the selected language when adding new views. Verify new UI in both languages.

Read the relevant tool document before changing its behavior. Update that document with any behavior change and add a separate Markdown file under `docs/` for each new tool.
